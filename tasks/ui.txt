# AI Agent Builder - UI/UX 상세 설계서

## 1. 개요
이 문서는 `prd-detail.txt`를 기반으로 AI Agent Builder의 프론트엔드 UI/UX를 사용자 플로우 관점에서 상세히 설계합니다. 각 페이지의 구조, 핵심 컴포넌트, 상태 관리, 사용자 인터랙션을 정의합니다.

---

## 2. 전체 레이아웃 및 네비게이션
- **공통 레이아웃 (AuthenticatedLayout)**:
  - **사이드바 (Sidebar)**: 로그인 후 모든 페이지에 공통으로 노출되는 주 네비게이션.
    - 메뉴 항목: 대시보드, AI Agents, 워크플로우, MCP 서버, 설정, 로그아웃.
    - 선택된 메뉴는 활성화 상태로 표시.
  - **헤더 (Header)**:
    - 현재 페이지 제목 표시.
    - 사용자 프로필 아이콘 (클릭 시 드롭다운 메뉴: 내 정보, 로그아웃).
  - **메인 콘텐츠 (Main Content)**:
    - 각 페이지의 실제 내용이 렌더링되는 영역.

---

## 3. 사용자 플로우별 UI 설계

### 3.1. 플로우 1: 사용자 온보딩 및 인증 (Authentication Flow)

#### **3.1.1. 로그인 페이지 (`/login`)**
- **목적**: 기존 사용자가 시스템에 접근합니다.
- **핵심 컴포넌트**:
  - `LoginForm`: 이메일, 비밀번호 입력 필드.
  - 소셜 로그인 버튼 (Google, Github).
  - "로그인" 버튼.
  - 회원가입 페이지로 이동하는 링크 (`/register`).
  - 비밀번호 찾기 링크.
- **인터랙션**:
  - 폼 유효성 검사 (입력값 필수, 이메일 형식).
  - 로그인 성공 시, 대시보드(`/`)로 리다이렉트.
  - 로그인 실패 시, 에러 메시지 (Toast 또는 폼 하단 텍스트) 표시.

#### **3.1.2. 회원가입 페이지 (`/register`)**
- **목적**: 신규 사용자가 계정을 생성합니다.
- **핵심 컴포넌트**:
  - `RegisterForm`: 이메일, 비밀번호, 비밀번호 확인 입력 필드.
  - "회원가입" 버튼.
  - 로그인 페이지로 돌아가는 링크 (`/login`).
- **인터랙션**:
  - 회원가입 성공 시, 확인 이메일 발송 안내 및 로그인 페이지로 리다이렉트.

### 3.2. 플로우 2: 메인 대시보드 (Dashboard Flow)

#### **3.2.1. 대시보드 페이지 (`/`)**
- **목적**: 로그인 후 사용자가 가장 먼저 마주하는 홈 화면. 프로젝트의 전반적인 현황을 파악합니다.
- **핵심 컴포넌트**:
  - `SummaryCard`: "총 Agent 수", "총 워크플로우 수", "최근 실행 상태" 등 요약 정보 카드.
  - `RecentActivityList`: 최근에 실행된 워크플로우 목록 (이름, 실행 시간, 성공/실패 상태).
  - `QuickAccessButtons`: "새 Agent 만들기", "새 워크플로우 만들기" 등 주요 기능으로 빠르게 이동하는 버튼.

### 3.3. 플로우 3: 통합 워크플로우 스튜디오 (Unified Workflow Studio)

#### **3.3.1. 워크플로우 스튜디오 페이지 (`/studio/:id`)**
- **목적**: 단일 페이지 내에서 AI Agent와 MCP 도구를 조합하여 워크플로우를 시각적으로 설계, 생성 및 편집합니다.
- **레이아웃**: 3단 패널 구조 (노드 라이브러리 | 워크플로우 캔버스 | 속성 패널)

- **Panel 1: 노드 라이브러리 (좌측)**
  - **목적**: 워크플로우를 구성하는 모든 빌딩 블록(노드)을 제공합니다.
  - **핵심 컴포넌트**:
    - `Accordion` 또는 `Tabs`로 섹션 구분.
    - **AI Agents 섹션**:
      - `SearchableList`: 사용자가 생성한 모든 AI Agent 목록.
      - 각 Agent 아이템을 캔버스로 드래그하여 "Agent 실행 노드"를 생성.
    - **MCP Tools 섹션**:
      - `TreeList`: 연결된 MCP 서버 목록을 표시. 각 서버를 확장하면 해당 서버가 제공하는 도구 목록이 나타남.
      - 각 도구 아이템을 캔버스로 드래그하여 "MCP 도구 실행 노드"를 생성.
    - **제어 흐름(Control Flow) 섹션**:
      - `DraggableNodeItem`: 조건 분기(If/Else), 반복(For Loop) 등 제어 노드.

- **Panel 2: 워크플로우 캔버스 (중앙)**
  - **목적**: 실제 워크플로우를 시각적으로 구성하는 메인 작업 공간입니다.
  - **핵심 컴포넌트**:
    - `WorkflowCanvasHeader`:
      - `EditableText` for 워크플로우 이름.
      - `SaveButton`: 현재 워크플로우 저장.
      - `ExecuteButton`: 워크플로우 실행 및 모니터링 뷰로 전환.
    - `WorkflowCanvas` (`React Flow` 기반):
      - 노드와 연결선(Edge)을 렌더링.
      - 노드 이동, 연결선 생성/삭제, 확대/축소, 패닝(panning) 기능.
      - 커스텀 노드: "Agent 노드", "MCP 도구 노드"는 각각 고유한 스타일과 아이콘을 가짐.

- **Panel 3: 속성 패널 (우측)**
  - **목적**: 캔버스에서 선택된 요소(노드, 연결선, 또는 캔버스 자체)의 상세 정보를 보고 편집합니다.
  - **핵심 컴포넌트**:
    - **워크플로우 설정 (아무것도 선택 안 함)**: 워크플로우의 전역 변수, 설명 등을 편집.
    - **노드 설정 (노드 선택 시)**:
      - 선택된 노드의 종류에 따라 동적으로 폼을 렌더링.
      - 예: Agent 노드 선택 시, 입력 데이터 매핑, 타임아웃 설정 등을 구성.
      - 예: MCP 도구 노드 선택 시, API 파라미터를 워크플로우의 다른 노드 출력값과 연결하는 UI 제공.

### 3.4. 플로우 4: 목록 관리 및 실행 기록

#### **3.4.1. 워크플로우 목록 페이지 (`/workflows`)**
- **목적**: 생성된 모든 워크플로우를 관리하고 실행 기록을 확인합니다.
- **핵심 컴포넌트**:
  - `WorkflowList`: 워크플로우 목록을 테이블/카드로 표시.
  - 각 항목의 "편집" 버튼은 **통합 워크플로우 스튜디오**(`/studio/:id`)로 이동시킵니다.
  - "새 워크플로우 만들기" 버튼도 스튜디오 페이지(`/studio/new`)로 이동합니다.
  - "실행 기록" 버튼은 해당 워크플로우의 기록 페이지로 이동합니다.

#### **3.4.2. Agent 관리 페이지 (`/agents`)**
- **목적**: 워크플로우에서 사용할 AI Agent를 사전 정의하고 관리합니다.
- **핵심 컴포넌트**:
  - Agent 생성/수정/삭제 기능을 제공. (이 페이지는 스튜디오와 별개로 Agent 자체를 관리하는 데 집중)

### 3.5. 플로우 5: 워크플로우 실행 및 모니터링 (Execution & Monitoring Flow)

#### **3.5.1. 실행 기록 페이지 (`/workflows/:id/history`)**
- **목적**: 특정 워크플로우의 과거 실행 기록을 확인합니다.
- **핵심 컴포넌트**:
  - `ExecutionHistoryList`: 실행 시간, 상태(성공/실패), 실행자 등을 테이블로 표시.
  - 각 기록 항목을 클릭하면 모니터링 상세 뷰로 이동.

#### **3.5.2. 모니터링 상세 뷰 (`/executions/:executionId`)**
- **목적**: 특정 실행 건의 각 노드별 상태와 입출력 데이터를 상세히 확인합니다.
- **핵심 컴포넌트**:
  - **Read-only WorkflowCanvas**: 실행된 워크플로우 구조를 시각적으로 표시.
    - 각 노드는 실행 상태(성공/실패/진행 중)에 따라 색상이 다르게 표시됨 (WebSocket으로 실시간 업데이트).
  - **LogPanel**:
    - 노드 클릭 시, 해당 노드의 입력 데이터, 출력 결과, 에러 로그 등을 탭(Tab) 형태로 보여줌.
