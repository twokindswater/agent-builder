# AI Agent Builder 상세 기능 명세서

## 1. 개요
이 문서는 AI Agent Builder의 상세 기능 명세서입니다. `prd.txt`의 내용을 기반으로 각 기능별 세부 요구사항, 기술적 사양, 사용자 시나리오를 구체화하여 정의합니다.

---

## 2. 핵심 기능 상세 명세 (Core Features)

### 2.1. AI Agent 생성기
- **기능 설명**: 사용자는 템플릿을 기반으로 AI Agent를 생성하고, 특정 목적에 맞게 설정을 커스터마이징할 수 있습니다.
- **세부 기능**:
  - **템플릿 기반 생성**:
    - 제공 템플릿: 챗봇, 데이터 분석 에이전트, 코드 생성 에이전트, 콘텐츠 생성 에이전트 등 사전 정의된 템플릿 제공.
    - 템플릿 선택 UI: 사용자가 템플릿 목록을 보고 선택할 수 있는 화면.
  - **Agent 설정 커스터마이징**:
    - 설정 항목: Agent 이름, 설명, 시스템 프롬프트(지시문), AI 모델 선택(GPT-4, Claude 3, Gemini 등), 모델 파라미터(Temperature, Max Tokens 등).
    - 설정 UI: 각 항목을 입력하고 수정할 수 있는 폼 기반의 인터페이스.
  - **Agent 관리 (CRUD)**:
    - 생성(Create): 새로운 Agent를 생성하고 저장.
    - 조회(Read): 생성된 Agent 목록 조회 및 상세 정보 확인.
    - 수정(Update): 기존 Agent의 설정 변경.
    - 삭제(Delete): 불필요한 Agent 삭제.

### 2.2. MCP(Model Context Protocol) 서버 연결
- **기능 설명**: 사용자는 외부의 MCP 서버를 시스템에 연결하여 해당 서버가 제공하는 도구들을 워크플로우에서 사용할 수 있습니다.
- **세부 기능**:
  - **서버 연결 관리**:
    - 연결 정보 입력: MCP 서버의 이름, URL, 인증 토큰 등을 입력하는 UI 제공.
    - 연결 테스트: 입력된 정보로 실제 서버에 연결하여 유효성을 검사하는 기능.
    - 서버 목록(CRUD): 연결된 MCP 서버 목록을 관리(추가, 조회, 수정, 삭제)하는 기능.
  - **도구 목록 조회**:
    - 연결된 MCP 서버가 제공하는 도구(Tool) 목록을 자동으로 불러와 UI에 표시.
    - 각 도구의 상세 정보(이름, 설명, 입력/출력 파라미터 등) 확인 기능.

### 2.3. 시각적 워크플로우 빌더
- **기능 설명**: 사용자는 드래그&드롭 방식의 시각적 UI를 통해 AI Agent와 MCP 도구들을 노드로 추가하고, 노드들을 연결하여 워크플로우를 구성합니다.
- **세부 기능**:
  - **워크플로우 캔버스**:
    - 노드를 배치하고 연결하는 무한 스크롤이 가능한 작업 공간.
    - 확대/축소, 전체 뷰 이동(Pan) 기능 지원.
  - **노드 시스템**:
    - 노드 종류: 시작(Start), 종료(End), AI Agent 실행, MCP 도구 실행, 조건 분기(If/Else), 반복(Loop), 데이터 변환 등.
    - 노드 팔레트: 사용 가능한 노드 목록을 제공하고, 캔버스로 드래그&드롭하여 추가.
  - **노드 연결 (Edges)**:
    - 노드의 출력(Output) 포트에서 다른 노드의 입력(Input) 포트로 드래그하여 연결.
    - 연결선은 데이터의 흐름을 시각적으로 표시.
    - 연결 유효성 검사 (예: 데이터 타입 일치 여부).
  - **워크플로우 관리**:
    - 저장/불러오기: 구성된 워크플로우를 저장하고, 나중에 다시 불러와 수정.
    - 버전 관리(v1.1+): 워크플로우의 변경 이력을 관리하고, 특정 버전으로 복원하는 기능.

### 2.4. 실시간 실행 및 모니터링
- **기능 설명**: 사용자는 구성한 워크플로우를 실행하고, 각 노드의 실행 상태와 결과를 실시간으로 모니터링할 수 있습니다.
- **세부 기능**:
  - **워크플로우 실행 엔진**:
    - 순차/병렬 실행: 워크플로우의 의존성에 따라 노드를 순차적 또는 병렬적으로 실행.
    - 비동기 처리: Celery와 같은 큐 시스템을 활용하여 오래 걸리는 작업을 비동기적으로 처리.
  - **실시간 모니터링 UI**:
    - 상태 시각화: 각 노드의 상태(대기, 진행 중, 성공, 실패)를 색상이나 아이콘으로 실시간 표시.
    - 데이터 확인: 각 노드의 입력값과 출력 결과를 확인할 수 있는 패널 제공.
    - 상세 로그: 워크플로우 전체 실행 로그 및 각 노드별 상세 로그 제공.
    - 실시간 업데이트: WebSocket을 사용하여 서버의 실행 상태를 프론트엔드로 즉시 푸시.

## 3. 기술 아키텍처 상세 (Technical Architecture)

- **Frontend**:
  - **프레임워크**: React (Vite 기반)
  - **상태 관리**: Redux Toolkit (복잡한 워크플로우 상태 관리용)
  - **UI 컴포넌트**: MUI 또는 Shadcn/ui (일관성 있는 디자인 시스템 구축)
  - **워크플로우 라이브러리**: React Flow (시각적 빌더 구현용)
  - **API 통신**: Axios (인터셉터 활용 등 고급 기능 지원)

- **Backend**:
  - **프레임워크**: FastAPI (Python, 비동기 지원)
  - **비동기 작업 큐**: Celery with Redis (워크플로우 실행 엔진)
  - **실시간 통신**: FastAPI-WebSocket (모니터링 기능)
  - **DB 연동**: SQLAlchemy (ORM)

- **데이터베이스 (Supabase)**:
  - **테이블 스키마**:
    - `users`: id, email, password_hash, created_at 등 (Supabase Auth 기본 제공)
    - `agents`: id, user_id, name, description, system_prompt, model_config (jsonb)
    - `mcp_servers`: id, user_id, name, url, encrypted_token
    - `workflows`: id, user_id, name, definition (jsonb), LATEST_VERSION
    - `workflow_versions`: id, workflow_id, version, definition (jsonb), created_at
    - `workflow_executions`: id, workflow_id, status, started_at, finished_at, results (jsonb)

- **인증**:
  - **방식**: Supabase Auth 활용 (JWT 기반). 소셜 로그인(Google, Github) 지원.

## 4. MVP 개발 로드맵 (Phase 1)
- **1단계: 사용자 인증 및 기본 설정**
  - [ ] Supabase Auth를 이용한 회원가입/로그인 UI 및 API 구현.
  - [ ] 로그인 후 기본 대시보드 화면 구성.
- **2단계: AI Agent 생성/관리 기능**
  - [ ] Agent 생성을 위한 UI (폼) 구현.
  - [ ] Agent 목록 조회 및 관리(수정/삭제) UI 구현.
  - [ ] Agent CRUD를 위한 백엔드 API 구현 및 Supabase 연동.
- **3단계: MCP 서버 연결 기능**
  - [ ] MCP 서버 정보 입력 및 저장을 위한 UI/API 구현.
  - [ ] 연결된 서버 목록 조회 기능 구현.
- **4단계: 기본 워크플로우 빌더**
  - [ ] React Flow를 활용한 기본 캔버스 및 노드 추가 기능 구현.
  - [ ] 노드 연결 기능 및 워크플로우 정의(JSON) 저장/불러오기 기능 구현.
- **5단계: 기본 실행 및 모니터링**
  - [ ] 저장된 워크플로우 정의를 순차적으로 실행하는 백엔드 로직 구현.
  - [ ] 실행 상태와 결과를 텍스트 로그 형태로 보여주는 기본 모니터링 화면 구현.
